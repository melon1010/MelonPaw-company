# 企业化剩余工作

本文只记录真实未完成项。SaaS、多租户计费、Kubernetes、CLI、Coding 模式和桌面客户端是明确不做，不列为缺陷。

## P0：生产安全与核心闭环

当前已落地的运行基线：Web 请求按用户解析 PERSONAL Agent；AgentScope `IsolationScope.USER` + DockerFilesystemSpec 隔离技能、文件和命令；官方 execute 是唯一 Shell 实现；普通用户工具页可见但不能切换到他人 Agent；个人模型从全局 ProviderManager 继承；定时任务记录执行者身份；请求上下文不能覆盖认证用户、Agent、会话或工作目录；工具审批按 Agent、用户、会话三层归属隔离。工作区上传、转写、渠道附件和技能远程下载已有大小上限、临时文件清理和公网 URL 策略；MCP 工具默认拒绝并在每次调用时按 Agent、用户和渠道重新判定；OneBot 反向 WebSocket 使用个人 Agent token 绑定。

### 1. 首次初始化部署验收

现状：没有用户时会要求 256 位初始化令牌；未通过环境变量注入时，后端写入 `${MELON_HOME}/bootstrap.token`，首个管理员创建后删除文件并关闭初始化入口。启动脚本只返回令牌文件路径，不把令牌写入日志。

验收：在 Linux 与 Windows 部署包上验证令牌文件权限、反向代理初始化、并发抢占和重启复用；禁止把令牌文件纳入普通备份或日志采集。

### 2. 敏感配置加密存储

现状：渠道和模型密钥在 API 响应中会掩码，但运行值仍随 Agent 配置明文写入 `config.yaml`。

验收：引入主密钥或外部密钥提供器；磁盘只保存密文；支持密钥轮换、备份恢复和日志脱敏；旧明文配置可一次性迁移。

### 3. 项目 Agent 与项目任务闭环

现状：项目成员和共享文档可用，但 `EnterpriseAgentAccessService` 明确禁用了普通成员执行项目 Agent，Agent 绑定表也只有 PERSONAL 流程形成完整闭环。

验收：实现项目 Agent 绑定、发布、成员可见范围、项目任务所有权、审批、配额、审计和结果归档；项目成员不能读取其他项目或个人状态。

### 4. 企业管理审计

现状：审计重点覆盖工具审批，用户、角色、项目、模型、插件、备份和安全策略变更没有统一不可抵赖记录。

验收：所有管理写操作记录操作者、目标、前后差异、时间、来源 IP、结果和关联请求 ID；审计员只读；提供保留期与导出策略。

### 5. 外部渠道入口信任边界

现状：轮询和 WebSocket 渠道可运行；OneBot 已按个人 Agent 的渠道 token 验证握手。钉钉、飞书和企业微信等通用 webhook 仍受应用 Bearer 登录保护，尚未形成每个渠道独立的签名校验、重放保护和限流闭环。

验收：按国内渠道实现签名/时间戳/nonce 校验、重放缓存、来源限制、速率限制和失败审计；通过后才允许匿名 webhook 到达渠道处理器。

### 6. 沙箱运行依赖与命令停止闭环

现状：生产默认要求 Docker 和 `melonpaw-company-sandbox` 镜像；当前开发机没有 Docker，因此尚未完成真实容器执行验收。停止请求会取消 AgentScope 调用订阅并触发 Agent 中断，Docker exec 子进程的强制回收仍需在有 Docker 的环境做集成测试。默认 `bridge` 只满足访问公网资料，不等于禁止企业内网；生产必须配置受控出口网络或代理。

验收：启动预检明确报告 Docker daemon、镜像、网络策略和资源限制；`sleep` 长命令在停止接口的 SLA 内退出；跨用户容器、挂载和快照不能互相读取。

## P1：企业运营能力

### 1. 统一非对话任务中心

现状：任务中心主要展示 Chat 元数据；Cron 执行、渠道任务、审批和项目任务分别存在。

验收：统一任务 ID、状态、发起人、触发方式、Agent、项目、执行时间、结果、审批和审计；任务可以完全不进入聊天页面完成创建、查看和重试。

### 2. 角色管理页面

现状：后端支持自定义角色和权限，成员页只能选择已有角色，没有独立角色设计与影响范围页面。

验收：提供角色列表、权限矩阵、创建编辑、被引用用户数和危险权限提示；系统角色不可修改。

### 3. 配额、并发与成本治理

现状：存在 Agent 级限流和用量统计，但没有用户/项目级预算、并发和自动化频率上限。

验收：支持用户、项目、Agent 三层额度；超限行为可预测；管理员可查看归因和调整记录。

### 4. 数据生命周期与灾备演练

现状：有备份接口，但没有企业级自动保留、恢复演练、个人数据归档和离职交接流程。

验收：定时备份、校验、保留策略、恢复演练；用户禁用后的会话、技能、渠道密钥和自动化可移交或销毁。

### 5. 可观测性与企业身份源

现状：只有基础健康接口和本地账号；缺少指标、告警、链路关联以及 LDAP/OIDC 等可选身份源。

验收：提供运行指标、结构化日志、请求/任务关联 ID 和关键告警；身份源可插拔且本地管理员保留应急入口。

## P2：去上游耦合与体验收尾

- Provider OAuth 当前返回 disabled；插件市场搜索返回空结果，应隐藏无效入口或完成真实实现。
- 旧前端插件下载器、`window.QwenPaw` SDK 和动态模块猴子补丁已删除；`@agentscope-ai/design` 的固定 `qwenpaw` CSS 前缀及少量兼容存储键仍需随依赖升级分阶段迁移。
- 多个 `*CompatController` 仍承担上游接口兼容，应在接口稳定后按领域重命名并建立正式 API 版本。
- 继续清理不可见乱码、旧注释和不再使用的国际化文案。
- 建立桌面和移动端浏览器截图回归、可访问性检查与关键企业流程端到端测试。
